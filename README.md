### Warna Utama
Warna utama yang dipilih adalah `#2563EB` (biru).

Warna ini dipilih karena sesuai dengan tema halaman koleksi game dan memberikan aksen yang jelas pada tombol, tautan, judul, serta elemen fokus.

### Token yang Digunakan

| Token | Nilai | Kegunaan |
|---|---|---|
| `--color-bg` | `#F8FAFC` | Latar halaman |
| `--color-fg` | `#0F172A` | Warna teks utama |
| `--color-surface` | `#FFFFFF` | Latar kartu dan panel |
| `--color-border` | `#D1D5DB` | Garis dan batas elemen |
| `--color-primary` | `#2563EB` | Tombol dan tautan |
| `--color-danger` | `#B00020` | Penanda kesalahan |
| `--color-focus` | `#2563EB` | Indikator fokus |
| `--radius-md` | `0.5rem` | Radius kartu dan tombol |
| `--space-4` | `1rem` | Jarak antar elemen |

### Kriteria Selesai
Jika nilai `--color-primary` pada `tokens.css` diubah dalam satu baris, warna tombol, tautan, judul, dan indikator fokus pada halaman ikut berubah.
