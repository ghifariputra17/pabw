## Deskripsi
Worksheet P9 membahas DOM dan event JavaScript untuk membuat halaman web interaktif. Halaman ini menampilkan daftar proyek, filter kategori, serta validasi formulir koleksi game.

## Implementasi
- Memilih elemen HTML menggunakan `querySelector()`.
- Membuat elemen dengan `createElement()`.
- Mengubah isi elemen dengan `textContent`.
- Menampilkan daftar proyek dari array objek.
- Menyaring proyek menggunakan `filter()`.
- Menangani klik menggunakan event delegation.
- Menandai tombol filter aktif.
- Menampilkan pesan ketika tidak ada proyek yang cocok.
- Menangani event `submit`.
- Mencegah reload menggunakan `preventDefault()`.
- Memvalidasi Nama Game, Genre, dan Platform.
- Menampilkan pesan kesalahan pada kolom wajib.
- Mengosongkan formulir setelah validasi berhasil.

## Struktur Berkas
- `profil.html` - halaman profil dan formulir game.
- `js/app.js` - data dan fungsi JavaScript.
- `js/dom.js` - manipulasi DOM, filter proyek, dan validasi.
- `js/script.js` - skrip tambahan.
- File CSS - styling halaman.

## Cara Menjalankan
1. Buka terminal di folder `worksheet-p9`.
2. Jalankan `python -m http.server 8000`.
3. Buka `http://localhost:8000/profil.html` di browser.
4. Uji filter proyek dan formulir Tambah Game.
